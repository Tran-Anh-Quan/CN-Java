1. MO TA DU AN
--------------------------------------------------------------------------------
Ten project: lab15-spring-final-project
Mo ta: Ung dung quan ly sinh vien va dang ky mon hoc su dung Spring Boot

Cong nghe su dung:
- Spring Boot 3.1.3
- Spring Data JPA (truy cap du lieu)
- Spring Security (xac thuc va phan quyen)
- Thymeleaf (template engine)
- H2 Database (co so du lieu in-memory)
- Maven (cong cu build)

3. CAC CHUC NANG CHINH
--------------------------------------------------------------------------------
3.1 Quan ly Sinh vien (Student)
   - Xem danh sach sinh vien
   - Tim kiem sinh vien theo ten
   - Them moi sinh vien (chi ADMIN)
   - Chinh sua sinh vien (chi ADMIN)
   - Xoa sinh vien (chi ADMIN)
   - Xem danh sach mon hoc cua sinh vien

3.2 Quan ly Mon hoc (Course)
   - Xem danh sach mon hoc
   - Tim kiem mon hoc theo ten
   - Them moi mon hoc (chi ADMIN)
   - Chinh sua mon hoc (chi ADMIN)
   - Xoa mon hoc (chi ADMIN)

3.3 Dang ky mon hoc (Enrollment)
   - Dang ky sinh vien vao mon hoc
   - Xem danh sach dang ky (theo sinh vien)
   - Cap nhat diem (chi ADMIN)
   - Xoa dang ky (chi ADMIN)
   - Khong cho phep dang ky trung lap (1 sinh vien - 1 mon hoc)

3.4 Xac thuc & Phan quyen (Security)
   - Dang nhap voi tai khoan
   - Dang xuat
   - Hai vai tro: ROLE_ADMIN va ROLE_USER
   - Trang 403 cho nguoi khong co quyen truy cap
   - Mat khau duoc ma hoa BCrypt

4. MO HINH DU LIEU (ERD)
--------------------------------------------------------------------------------
    +-------------+         +---------------+         +-------------+
    |  STUDENTS   |         |  ENROLLMENTS  |         |   COURSES   |
    +-------------+         +---------------+         +-------------+
    | id (PK)     |<---+    | id (PK)       |    +-->| id (PK)     |
    | name        |    |    | student_id(FK)|    |    | course_code |
    | email       |    +----| course_id(FK) |----+    | course_name |
    +-------------+         | enrolled_at   |         | credits     |
                            | grade         |         +-------------+
                            +---------------+

    +-------------+
    |  APP_USERS  |
    +-------------+
    | id (PK)     |
    | username    |
    | password    |
    | role        |
    +-------------+

Quan he:
- Student 1:N Enrollment (1 sinh vien co nhieu dang ky)
- Course 1:N Enrollment (1 mon hoc co nhieu dang ky)
- Enrollment: quan he Nhiều-Nhiều giữa Student và Course

6. HUONG DAN CHAY
--------------------------------------------------------------------------------
Cach 1: Chay truc tiep

Cach 2: Build jar roi chay
    mvn clean package
    java -jar target/lab15-spring-final-project-0.0.1-SNAPSHOT.jar

Truy cap ung dung: http://localhost:8080
H2 Console: http://localhost:8080/h2-console
   - JDBC URL: jdbc:h2:mem:lab15db
   - Username: sa
   - Password: (de trong)
