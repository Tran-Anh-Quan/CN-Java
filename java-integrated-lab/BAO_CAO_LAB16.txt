1. GIỚI THIỆU ĐỒ ÁN
================================================================================

Hệ thống Quản lý Đơn hàng Đa nền tảng (Multi-Platform Order Management System)
được xây dựng nhằm thể hiện khả năng tích hợp 3 công nghệ Java khác nhau
trong cùng một nghiệp vụ, sử dụng chung một cơ sở dữ liệu H2 embedded
(multi-platform mode).

Kiến trúc hệ thống:
  - Customer Portal    : Jakarta EE 10 (Servlet 6.0, JSP, JSTL)
  - Warehouse Desktop  : Java Swing + FlatLaf Look & Feel
  - Management Portal  : Spring Boot 3.2 (Thymeleaf, Spring Security)
  - Shared Module      : H2 Database, các entity/enum/repository dùng chung
  - Database           : H2 file-based (./data/ordersystem) với AUTO_SERVER=TRUE

Luồng nghiệp vụ chính:
  Khách tạo đơn (Jakarta) → Kho tiếp nhận (Swing) → Kho đóng gói →
  Quản lý phê duyệt (Spring) → Giao hàng → Khách xác nhận hoàn thành (Jakarta)

Mỗi bước đều ghi nhật ký vào bảng order_history với platform, user, IP/hostname,
hỗ trợ truy vết end-to-end.

A. LỖI NGHIÊM TRỌNG (BLOCK BUILD / RUNTIME)

  [1] Package name trùng keyword Java
      - File  : shared/.../enum/*.java
      - Lỗi  : package vn.edu.eaut.lab16.shared.enum
                → 'enum' là keyword Java, không hợp lệ làm tên package
                → toàn bộ shared module compile fail
      - Fix  : đổi tên thư mục enum → enums, cập nhật package + toàn bộ
                12 file import trong 4 module

  [2] Class Order thiếu setter setTotalAmount
      - File  : shared/.../entity/Order.java
      - Lỗi  : chỉ có getter getTotalAmount() tính từ items,
                CreateOrderServlet/DatabaseConnection gọi setTotalAmount()
                gây compile error
      - Fix  : thêm method setTotalAmount() rỗng làm stub an toàn

  [3] JSP import sai package không tồn tại
      - File  : create-order.jsp, order-confirmation.jsp
      - Lỗi  : <%@ page import="vn.edu.eaut.customer.model.Product" %>
                → class không tồn tại, JSP fail compile → trang trắng 500
      - Fix  : đổi sang vn.edu.eaut.lab16.shared.entity.Product

  [4] Form create-order thiếu field username
      - File  : create-order.jsp + CreateOrderServlet.java
      - Lỗi  : servlet đọc getParameter("username") nhưng form không có
                → mọi audit ghi "anonymous", không truy vết được khách
      - Fix  : thêm input username + đọc từ session sau khi login

  [5] FlatDarkLaf ở package sai
      - File  : WarehouseApp.java
      - Lỗi  : import com.formdev.flatlaf.themes.FlatDarkLaf (sai)
      - Fix  : import com.formdev.flatlaf.FlatDarkLaf (đúng)

7. HƯỚNG DẪN CHẠY
================================================================================

Yêu cầu: JDK 17+, Maven 3.8+, port 8080 và 8081 rảnh.

Bước 1 - Build toàn bộ:
  cd D:\Java\java-integrated-lab
  mvn clean package

Bước 2 - Chạy Customer Portal:
  cd customer-portal-jakarta
  mvn jetty:run
  → mở http://localhost:8080/

Bước 3 - Chạy Warehouse Desktop (terminal khác):
  cd warehouse-desktop-swing
  mvn exec:java -Dexec.mainClass="vn.edu.eaut.warehouse.WarehouseApp"

Bước 4 - Chạy Management Portal (terminal khác):
  cd management-portal-spring
  mvn spring-boot:run
  → mở http://localhost:8081/login

Lưu ý: cả 3 nền tảng dùng chung 1 file H2 (./shared/data/ordersystem.mv.db)
qua AUTO_SERVER=TRUE nên thay đổi ở portal nào sẽ hiện ở cả 3 nơi.

8. KẾT LUẬN
================================================================================

Đồ án đã hoàn thành các yêu cầu của 10 bài lab về:
  - Tích hợp đa nền tảng Jakarta EE + Swing + Spring Boot
  - Đồng bộ dữ liệu qua cơ sở dữ liệu H2 dùng chung
  - Đầy đủ nghiệp vụ CRUD + workflow 5 trạng thái
  - Tìm kiếm đa điều kiện có phân trang
  - Optimistic locking phát hiện xung đột dữ liệu
  - Dashboard thống kê với 8 chỉ số KPI
  - Audit trail đầy đủ với IP/hostname tracking

Trong quá trình kiểm tra đã phát hiện và sửa 9 lỗi (5 nghiêm trọng,
2 bảo mật, 2 logic), đồng thời cải tiến toàn bộ giao diện 3 nền tảng
theo phong cách nhất quán với CSS variables chung, fragment layout
cho Spring Boot, FlatLaf theme cho Swing.

Build thành công trên JDK 17, tất cả 4 module compile và package
đầy đủ (WAR + 3 JAR). Hệ thống sẵn sàng demo end-to-end.
